# 全場 5v5 籃球

手機瀏覽器就能玩的 3D 全場 5 對 5 籃球（NBA 規格場地與規則）。

- 線上玩：<https://gajuioredvmn.github.io/basketball-5v5/>
- 全螢幕：iPhone 用 Safari 開 →「分享」→「加入主畫面」；Android 用 Chrome 開 → 按遊戲裡的「全螢幕」或「加到主畫面」。

## 檔案

| 路徑 | 說明 |
|---|---|
| `index.html` | 打包好的遊戲（單一檔案，含 three.js），GitHub Pages 直接提供這個 |
| `manifest.webmanifest`、`icon-*.png` | 加到主畫面用的設定與圖示 |
| `source/src/main.js` | 遊戲邏輯：規則、AI、操控、鏡頭、模式、轉播 |
| `source/src/player.js` | 球員模型（蒙皮骨架）、球衣貼圖、動作 |
| `source/src/arena.js` | 球館：NBA 尺寸球場、籃架、看台、燈光 |
| `source/src/audio.js` | 音效（WebAudio 合成） |
| `source/src/const.js` | 尺寸常數、球隊顏色 |
| `source/src/index.html` | 介面版型與樣式（打包時把程式塞進去） |

## 修改後重新打包

```bash
cd source
./build.sh        # 需要 Node.js 與 Python 3，會輸出 ../index.html
```

改的是 `source/`，不要直接改根目錄的 `index.html`（會被打包覆蓋）。

## 已完成

- NBA 規格球場與規則：24／14 秒、8 秒、回場、進攻與防守 3 秒、干擾球、犯規與罰球、加罰、6 犯離場、暫停、換人與體力、NBA 計時
- 操控：投籃時機條、傳球、運球招式（胯下、背後、後撤步、猶豫步、轉身）、歐洲步、後仰、背打（勾射、夢幻腳步）、灌籃（掛框、慢動作）、空中接力
- AI：人盯人／2-3 區域／全場緊迫、擋拆與換防、包夾、低位單打、三分戰術
- 籃板：投籃出手後防守方轉身卡位、進攻方長人衝搶；被卡在身後會變慢，籃板能力強的偶爾能繞過去
- 模式：單場、季後賽搶四、三分大賽、灌籃大賽、練習（一個人自由投籃，球自動回到手上）、教學（10 個步驟）；球隊顏色可選
- 場邊：主場啦啦隊 6 人（平常站在遠側底線角落，暫停時進場表演）、吉祥物大頭熊（在遠側底線走動，主隊得分會揮手、後空翻）
- 球員特長：每人一種（控球大師、神射手、飆速、防守尖兵、全能、灌籃高手、籃板悍將、護框、低位、空間大個），能力差異會影響命中率、甜蜜點寬度、彈跳、傳球、電腦的出手習慣；換人面板顯示特長與最強兩項能力值
- 大螢幕：中場正上方懸吊（底部離地 10m），四面播放現場即時畫面，下方 LED 帶顯示比分與時間；暫停時鏡頭會先抬頭看大螢幕
- 動作：骨架有腳踝、手腕、腰、胸、脖子；跳投分段（下蹲收球→起跳到出手點→出手壓腕→落地緩衝）、上籃前兩步收球、頭會看球、接球伸手、累了扶膝、急停後仰；傳球分胸前、地板、過頂、單手快傳
- 跳躍：球員重力較大，高度不變但滯空時間變短；落地會緩衝減速，加速與煞車更俐落
- AI：拉開空間、傳球後換位或傳切、被阻絕就後門切、V 字切；協防與輪轉補位、補防衝出去封；切入引包夾後分球；快攻分路與回防先守籃下
- 滑鍵：手指不用放開，從一個鍵滑到另一個鍵就等於按下；從「加速」滑到「投籃」時加速會維持到手指放開（衝刺中上籃、灌籃）
- 點擊傳球：持球時直接點場上的隊友就傳給他；防守時點隊友就改控制他（輕點才算，不會跟搖桿衝突）
- 腳步不滑：每隻腳踩地時記住在場上的位置，踩地期間反算髖關節讓腳完全不動（轉身、加減速、側滑都一樣）；抬腳時才跨到下一步；站著離站位太遠就跨一步過去。跑步時下半身會轉向移動方向
- 真人動作：跳投、走動運球（CMU 動作捕捉）、跑動運球（含真實球路）、上籃、搶籃板、接球（SkillMimic BallPlay-M），轉到遊戲骨架並對齊遊戲時間；來源與授權見 THIRD_PARTY.md
- 數據：比賽數據裡的「投籃熱區」：半場圖、禁區／中距離／三分依命中率上色，可切換球隊與球員
- 轉播：電視記分條、賽前介紹、精彩重播、語音播報（字幕在最下方）、關鍵時刻、全場最佳
- 設定：按鈕大小、左右手、拖曳按鈕位置、震動、畫質

## 投籃機制

- 跳投：按住投籃、在力道條的綠色甜蜜點放開。甜蜜點寬度依距離、防守貼身程度、跑動與體力而變；命中甜蜜點時空檔約 97%、有人干擾約 88%、貼身約 72%。
- 太早放開球會偏短打前框，太晚會偏長打後框或籃板。
- 上籃、灌籃不需要時機；空中再按「招式」＝拉桿（收球換手，避開封阻）；沿底線切入、搖桿推向另一側＝反手上籃。
